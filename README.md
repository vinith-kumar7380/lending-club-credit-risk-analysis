# Lending Club – Credit Portfolio & Risk Analysis

## Project Overview
An end-to-end data analytics project using historical
LendingClub loan data to explore loan portfolio
performance and credit risk.

## Dataset
Source: Kaggle – LendingClub Loan Data (2007–2018)

https://www.kaggle.com/datasets/wordsforthewise/lending-club

## Tools & Technologies
- Microsoft Excel
- SQL
- Python (Pandas, NumPy, Matplotlib)
- Power BI

## Project Objectives
- Understand loan portfolio performance
- Analyse loan repayment outcomes
- Identify data quality issues
- Explore credit risk patterns
- Build an interactive Power BI dashboard

## Project Status
In Progress

## Disclaimer
This project uses publicly available historical
data for educational and portfolio purposes.
